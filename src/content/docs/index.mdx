import { Card, CardGrid } from '@astrojs/starlight/components';

```sh
docker run -p 7070:7070 ghcr.io/monolock-dev/monolock
```

<CardGrid stagger>
	<Card title="One connection, one lock" icon="seti:lock">
		A TCP connection is one claim on one named lock. Closing the connection
		*is* the release — there is no release call to forget, and the next
		waiter in the FIFO queue is promoted at once.
	</Card>
	<Card title="No dependencies, no database" icon="seti:go">
		A single static binary built on the Go standard library alone. No
		config file, no storage, no cluster to babysit — one process is the
		whole deployment.
	</Card>
	<Card title="Fencing tokens built in" icon="seti:license">
		Every grant carries a monotonically growing token. Pass it to the
		resource the lock guards and stale holders fence themselves out —
		safety on top of liveness.
	</Card>
	<Card title="Client-chosen leases" icon="setting">
		Each client picks its own failure-detection window per connection.
		Heartbeats are RTT-aware, and a dead holder is detected within one
		lease — while a healthy one can hold forever.
	</Card>
	<Card title="Production-grade operations" icon="rocket">
		TLS and mTLS with `SIGHUP` rotation, identity-based ACL authorization,
		a JSON audit log of every ownership change, an admin API, Prometheus
		metrics and health endpoints.
	</Card>
	<Card title="Simple by design" icon="approve-check">
		A single point of coordination — no replication, no quorum, no
		consensus. Know exactly what you get, and what you don't.
	</Card>
</CardGrid>
